# TemplateIcon

Description: Monochrome outline icon for a template, picked from its name by `templateIcon()` (`app/utils/templates/template-preview.ts`): calendar for meetings, sun for daily / standup, bolt for bugs, paper plane for specs, chart for reports, clipboard for checklists, document otherwise. Used by the template picker and the empty-note pills.

## Props
| Prop | Type | Default | Description |
|---|---|---|---|
| name | `string` | | Template name |
| size? | `number` | 16 | Icon size in px |
| className? | `string` | | Extra classes |
