# templates

Pure modules behind vault templates: plain `.md` files in `_templates/` at the vault root (directly, or one folder down in a pack) whose `{{tokens}}` expand when a template is used. No React, no file I/O (the hooks in `app/hooks/file-system/use-template-*.ts` read and write).

| File | Purpose |
|---|---|
| `template-tokens.ts` | `TEMPLATE_TOKENS` (the listed set: `{{date}}` `{{time}}` `{{title}}` `{{year}}` `{{month}}` `{{day}}` `{{weekday}}` `{{weekdayShort}}` `{{monthName}}` `{{monthNameShort}}` `{{week}}` `{{quarter}}` `{{slug}}` `{{clipboard}}` `{{selection}}` `{{cursor}}`, plus `{{prompt:Label}}`; names match in any case, so `{{Year}}` is `{{year}}`), `LEGACY_TEMPLATE_TOKENS` (`weekSheet` `monthSheet` `quarterSheet` `yearSheet`: still expanded in existing templates, never listed, suggested or warned about), `expandTemplate()` (one left-to-right pass; `{{date:FORMAT}}` / `{{time:FORMAT}}` via `formatDate()`: YYYY YY MMMM MMM MM M dddd ddd DD D HH H mm ss, `ww` (ISO week, 01-53), `GGGG` (the ISO week's year: 2027-01-01 is `2026-W53`), `Q` (quarter, 1-4), `[literal]`; date math `{{date+1d}}` / `-2w` / `+1m` / `+1y` (`shiftDate()`, months keep the day within the target month), combinable: `{{date-1w:GGGG-[W]ww}}`; inserted text is never expanded again; any other `{{name}}` is a blank and stays literal; the first `{{cursor}}` becomes an offset and the rest are removed), `parseTemplateToken()`, `isValidToken()`, `isBlankToken()`, `templateTokenRegex`, `slugify()`, `usesToken()`, `extractPromptLabels()` (distinct, trimmed, first-appearance order), `offsetToLineColumn()` |
| `folder-template.ts` | Folder templates (`_templates/<F>/` whose README.md has `scaffold: true`), pure: `planScaffold(source, ctx)` expands names (prompts written `{{Label}}` or `{{prompt:Label}}`, any `{{…}}` that isn't a name token asking for it, since `:` can't be used in names on Windows and macOS; and date/time tokens without a format, forbidden characters become `-`) and `.md` bodies (`scaffold` key dropped), finds empty names and case-insensitive clashes; `namePromptLabels`, `newFolderTemplatePlan(folderName, entries)` (a new folder template for `writeScaffold`: the root README marked `scaffold: true`, or a frontmatter-only one made), `scaffoldPromptLabels` (top name, entry names, bodies; each once), `scaffoldUsesClipboard`, `expandNameSegment`, `folderTemplateDisplayName`. Disk side in `hooks/file-system/folder-template-ops.ts`. |
| `template-frontmatter.ts` (`dropKeys` option: extra keys `templateContent` removes) | `templateContent()` drops column-0 YAML comment lines and the retired keys (`target_folder`, `file_name`; they no longer do anything, only kept out of notes) from the frontmatter, dropping the block if nothing else is left; `templateBody()` is the text after the frontmatter block |
| `template-registry.ts` (also `sanitizePackName` (a pack's folder name, one safe path segment), `listFolderTemplates`/`isScaffoldFlag`: a subfolder with a `scaffold: true` README is a folder template, not a pack; `listTemplates` and `groupTemplatePacks` take an `exclude` set of those names) | `TEMPLATES_FOLDER` (`_templates`), `resolveTemplatesFolder(paths)` (always `_templates`; `exists` when it holds a file directly or in a pack), `listTemplates()` / `isTemplatePath()` (`.md` files directly in the folder, or in one of its direct subfolders, a template pack: `_templates/Journal/Daily.md` gets `pack: "Journal"`; loose ones first, then by pack and name), `groupTemplatePacks()` (the Templates page's groups, loose first, empty pack folders included), `matchTemplateForName()` (the one template-suggestion rule: the template a new note's name points to: its folder, `rfcs/` ↔ `rfc.md` / `rfcs.md`, else a template whose name starts it word for word, longest first, else a journal-like template for a date name; it only preselects, in the missing-link picker and the WikiLink dialog's From template), `suggestTemplateName()` (first `# Heading` without fields, else the note title; for "Save as template…"), `parseMissingLink()` (a missing `[[folder/name|alias#heading]]` → vault-root folder + base name), `sanitizeNoteName()`, `sanitizeTemplateFileName()` (base name only, no `..` or leading dots, `.md` added, empty → `template.md`; shared by AI chat and "New template…") |
| `template-preview.ts` | `templateIcon()` (an icon key from the name), `templateSummary()` ("3 sections • Action items • Today's date • Asks Owner", or "Plain note") and `templatePreview()` (the note a template makes now: frontmatter as property rows, lines as heading / task / bullet / text with unanswered questions as pill segments, blank runs collapsed) for the picker and the empty-note pills |
| `template-packs.ts` | The built-in note examples, used from memory, never written on their own: `STARTER_TEMPLATES` (Meeting notes, Project brief; paths `builtin:…` are ids: empty-note pills, picker, wizard examples, the Templates page's Examples) and `builtinNoteTemplates(vaultTemplates)` (them under the "Built-in" pack, minus names the vault already has); the `BuiltinTemplate` / `BuiltinPack` shapes the folder examples use. There is no pack catalogue: templates are the user's own, made with the template wizard. Raw bodies, never expanded on write |
| `template-folders.ts` | `BUILTIN_FOLDER_TEMPLATES`: the built-in folder examples (never installed on their own; the wizard copies one under the name given). Same `BuiltinPack` shape (nested names such as `Meetings/Kickoff` allowed, `displayName` for lists). `builtinFolderSource(pack)` (one as a `ScaffoldSource`, so "New from folder template…" uses it from memory). Project folder (`{{Project name}}/`: README with `scaffold: true` and `# {{title}}`, Tasks, Decisions with `{{date}}`, Meetings/Kickoff) and Research folder (`{{Research topic}}/`: README with Question / Findings / Next steps, Sources table, Open questions), so using one asks for the name and makes a folder of that name (no `:` in names, which Windows and macOS refuse). Raw bodies |
| `template-fields.ts` | Plain names for fields: `fieldLabel()` ("Today's date", "Ask: Owner", "Fill in: Task 1", "Tomorrow's date", "Today's date (dddd)"; legacy tokens keep their names; null for non-fields), `humanizeBlank()`, `blankName()`, `templateFieldOptions()` (the field menu: the doc's questions first, then "Ask a question…" and "Blank to fill in…", then every `TEMPLATE_TOKENS` entry with today's value or its description, then the date presets: Tomorrow's date, Yesterday's date, Long date, This week's name) and `matchFieldOptions()` (token-name prefix or a word of the plain name, in any case) |
| `template-lint.ts` | `lintTemplate()` (non-blocking, plain-language warnings: likely typos of a listed token such as `{{dat}}` (other names are blanks, legacy tokens are fine), math or a format on the wrong token, text that isn't a field, empty prompt label, several cursors, a leftover `target_folder` or `file_name`) `TOKEN_DESCRIPTIONS` (one line per listed token, shared with `template-fields.ts`) and `TEMPLATE_SYNTAX_GUIDE` (the grammar as Markdown, built from `TEMPLATE_TOKENS`, with the period formats; the AI chat's template skill embeds it) |

Times are local and names English, so output doesn't depend on the browser locale.
