# templates

Pure modules behind vault templates: plain `.md` files in a templates folder whose `{{tokens}}` expand when a template is used. No React, no file I/O (the hooks in `app/hooks/file-system/use-template-*.ts` read and write).

| File | Purpose |
|---|---|
| `template-tokens.ts` | `TEMPLATE_TOKENS`, `expandTemplate()` (one left-to-right pass: `{{date}}` `{{time}}` `{{weekday}}` `{{weekdayShort}}` `{{year}}` `{{month}}` `{{day}}` `{{monthName}}` `{{monthNameShort}}` `{{week}}` (ISO, `isoWeek()`) `{{quarter}}` `{{weekSheet}}` `{{monthSheet}}` `{{quarterSheet}}` `{{yearSheet}}` (week / month / quarter / year names via `periodOf`, e.g. `2026-W42`, date math allowed) `{{title}}` `{{slug}}` `{{clipboard}}` `{{selection}}` `{{cursor}}` `{{prompt:Label}}`, plus `{{date:FORMAT}}` / `{{time:FORMAT}}` (`formatDate()`: YYYY YY MMMM MMM MM M dddd ddd DD D HH H mm ss, `[literal]`) and date math `{{date+1d}}` / `-2w` / `+1m` / `+1y` (`shiftDate()`, months keep the day within the target month); inserted text is never expanded again; any other `{{name}}` is a blank and stays literal; the first `{{cursor}}` becomes an offset and the rest are removed), `parseTemplateToken()`, `isValidToken()`, `isBlankToken()`, `templateTokenRegex`, `slugify()`, `usesToken()`, `extractPromptLabels()` (distinct, trimmed, first-appearance order), `offsetToLineColumn()` |
| `template-frontmatter.ts` | `splitTemplate()` drops column-0 YAML comment lines and takes the routing keys (`target_folder`, `file_name`) out of the frontmatter (dropping the block if nothing else is left) and returns the raw `file_name` (`target_folder` is no longer used, only kept out of notes); `templateBody()` is the text after the frontmatter block |
| `template-registry.ts` | `resolveTemplatesFolder()` (the per-vault setting, else the first existing of `templates`, `_templates`, `Templates`), `listTemplates()` / `isTemplatePath()` (`.md` files directly in the folder, or in one of its direct subfolders, a template pack: `templates/Journal/Daily.md` gets `pack: "Journal"`; loose ones first, then by pack and name), `groupTemplatePacks()` (the Templates page's groups, loose first, empty pack folders included), `matchTemplateForFolder()` (`rfcs/` ↔ `rfc.md` / `rfcs.md`), `matchTemplateForName()` (the template a new note's name points to: its folder, else a template whose name starts it word for word, longest first, else a journal-like template for a date name; the WikiLink dialog's From template preselects it), `suggestTemplateName()` (first `# Heading` without fields, else the note title; for "Save as template…"), `parseMissingLink()` (a missing `[[folder/name|alias#heading]]` → vault-root folder + base name), `sanitizeNoteName()`, `sanitizeTemplateFileName()` (base name only, no `..` or leading dots, `.md` added, empty → `template.md`; shared by AI chat and "New template…") |
| `template-preview.ts` | `templateIcon()` (an icon key from the name), `templateSummary()` ("3 sections • Action items • Today's date • Asks Owner", or "Plain note") and `templatePreview()` (the note a template makes now: frontmatter as property rows, lines as heading / task / bullet / text with unanswered questions as pill segments, blank runs collapsed) for the picker and the empty-note pills |
| `template-packs.ts` | `BUILTIN_PACKS`: the packs the Templates page offers to add (Journal: Daily / Weekly / Monthly / Yearly, dated by `file_name` in `journal/{{year}}`, and Log entry; Meetings; Writing; Projects), each `{ id, name, description, templates: { name, description, body }[] }`; `packTemplatesInVault(pack, folder, paths)` (which are already in `<folder>/<pack>/`, ignoring case). Bodies are raw, never expanded on write |
| `template-starter.ts` | `TEMPLATE_STARTERS`: what "New template…" offers to start from (Basic, Journal, Log entry, Meeting notes, Spec, Report; the bodies are exported for the built-in packs; each `{ name, suggestedName, description, body }`). Plain Markdown with no comments or routing; metadata such as `author: {{prompt:Author}}` / `status: Draft` as frontmatter keys. `TEMPLATE_STARTER` is Basic (`# {{title}}`, `{{date}}`, one `{{prompt:Owner}}`, `{{cursor}}`); never expanded on write |
| `template-fields.ts` | Plain names for fields: `fieldLabel()` ("Today's date", "Ask: Owner", "Fill in: Task 1", "Tomorrow's date", "Today's date (dddd)"; null for non-fields), `humanizeBlank()`, `blankName()`, `templateFieldOptions()` (the field menu: the doc's questions first, then "Ask a question…" and "Blank to fill in…", then every `TEMPLATE_TOKENS` entry, then "Tomorrow's date" with today's value or its description) and `matchFieldOptions()` (token-name prefix or a word of the plain name) |
| `template-lint.ts` | `lintTemplate()` (non-blocking, plain-language warnings: likely typos of a token such as `{{dat}}` (other names are blanks, not warned about), math or a format on the wrong token, text that isn't a field, empty prompt label, several cursors, a misspelled `file_name`, a leftover `target_folder`) `TOKEN_DESCRIPTIONS` (one line per token, shared with `template-fields.ts`) and `TEMPLATE_SYNTAX_GUIDE` (the grammar as Markdown, built from `TEMPLATE_TOKENS`; the AI chat's template skill embeds it) |

Times are local and names English, so output doesn't depend on the browser locale.
