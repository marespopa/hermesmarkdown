# GoogleDocsToMarkdownToolLoader

Description: Loads `MarkdownCleanerTool` client-only for `/tools/google-docs-to-markdown`, preset to HTML input with a Google Docs hint. `CleanerSkeleton` ([ToolSkeletons](../components/ToolSkeletons.md)) outlines the tool while it loads.

## Local State & Storage
- State: none. Persistence: none.

## Dependencies
- Core: `next/dynamic`, `MarkdownCleanerTool`.
- Zero-Cloud: no network or telemetry side effects.

## Quick Usage
```tsx
<GoogleDocsToMarkdownToolLoader />
```
