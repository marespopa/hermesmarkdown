# MermaidToolLoader

Description: Loads `MermaidTool` client-only (`next/dynamic`, `ssr: false`), since the source lives in sessionStorage, with `MermaidSkeleton` ([ToolSkeletons](../components/ToolSkeletons.md)) outlining the tool while it loads. `mermaid` itself is fetched on the first render.

## Local State & Storage
- State: none. Persistence: none.

## Quick Usage
```tsx
<MermaidToolLoader />
```
