# CsvToMarkdownTableToolLoader

Description: Loads `TableTool` client-only for `/tools/csv-to-markdown-table`, with its CSV import open (`csvImportOpen`). `TableSkeleton` ([ToolSkeletons](../components/ToolSkeletons.md)) outlines the tool while it loads.

## Local State & Storage
- State: none. Persistence: none.

## Dependencies
- Core: `next/dynamic`, `TableTool`.
- Zero-Cloud: no network or telemetry side effects.

## Quick Usage
```tsx
<CsvToMarkdownTableToolLoader />
```
