# TableToolLoader

Description: Loads `TableTool` client-only (`next/dynamic`, `ssr: false`): the grid is a CodeMirror view and the table lives in sessionStorage. A fixed-height skeleton keeps the page from shifting, and CodeMirror is fetched only on this route.

## Local State & Storage
- State: none. Persistence: none.

## Quick Usage
```tsx
<TableToolLoader />
```
