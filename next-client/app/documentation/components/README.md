# Documentation components

Pieces of the `/documentation` page (`../page.tsx`). Article content lives in `../content/`; shared content building blocks (`Code`, `Callout`, `KV`, `ShortcutGroups`) in `../doc-primitives.tsx`.

| Component | Purpose |
|---|---|
| [DocsLocalNav](DocsLocalNav.md) | Docs bar that sticks under the site header: title, section links, Contents button (mobile), Open Editor. |
| [DocsHero](DocsHero.md) | "How can we help?" opening with the search field that filters every article. |
| [TopicCards](TopicCards.md) | One rounded card per section: icon, name, summary, article count. |
| [DocsSidebar](DocsSidebar.md) | Table of contents with the article in view highlighted; desktop sidebar and mobile Contents sheet. |
