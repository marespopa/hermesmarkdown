# SidebarSystemFilters

Description: The smart filters above the sidebar's Files and Tags views: All Notes, Untagged, Todo (an open task), Today (changed today) and Archive (in a folder named Archive or .archive), each with how many notes it holds (`useTagIndex`, so Privacy Mode applies to the counts). A click lists the notes on the Tags page (`?filter=`), rewriting the URL in place when already there (`useTagNavigation`); the filter showing is highlighted. Reads the URL, so it sits in a Suspense boundary.
