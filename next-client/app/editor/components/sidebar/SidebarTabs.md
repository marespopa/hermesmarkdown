# SidebarTabs

Description: The Files / Tags switch under the sidebar's header, a segmented control (`role="tablist"`). The choice is `atom_activeSidebarTab`, the phone drawer's tab atom too.

## Props
| Prop | Type | Description |
|---|---|---|
| tab | `"files" \| "tags"` | The view showing |
| onChange | `(tab) => void` | Called with the view picked |
