# MobileDrawer

The phone's navigation: a left drawer (Files and Tags) and a right drawer (Outline and metrics), mounted by `EditorShell` on mobile chrome once the vault is unlocked (not on Settings).

| Item | Purpose |
|---|---|
| [MobileDrawer](MobileDrawer.md) | Left drawer: Files / Tags tabs, Settings at the foot. |
| [MobileOutlineDrawer](MobileOutlineDrawer.md) | Right drawer: the note's headings and word, character and line counts. |
| [FilesPane](FilesPane.md) | Files tab: the sidebar's Files section. |
| [TagsPane](TagsPane.md) | Tags tab: system filters and the nested tag tree. |
| [use-edge-swipe](use-edge-swipe.md) | Edge swipes that open the drawers, and swipes that close them. |
