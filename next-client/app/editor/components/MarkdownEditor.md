# MarkdownEditor

Description: CodeMirror 6 Markdown editor for one pane. It adds inline pills and callouts (links, dates, tags), an inline editable table grid with spreadsheet formulas (including cross-note references), a slash menu grouped into sections and searched by name, alias and description, whose basic blocks (headings, lists, quote, divider) turn the caret's line into that block (`codemirror/slash-commands.ts`), a `{` emoji menu over every Unicode emoji, searched by name, alias and keyword (`codemirror/emoji-completion.ts`, `codemirror/emoji-index.ts`), a frontmatter menu of the vault's keys, tags and repeated values (`codemirror/frontmatter-completion.ts`), inline-rendered Mermaid diagrams and display math (double-click to edit the source), `![[Note]]`, `/Note.md` and `/data.csv` embeds shown read-only under their line (`codemirror/note-embeds.ts`, loaded and pushed in by `useNoteEmbeds`), a `/board` slash entry that creates a named board and links it at the caret (`useInsertBoardLink`), an **Embed file** slash entry (with a vault) that leaves a bare `/` on its own line and reopens the menu there to pick a note or type a file path (`insertEmbedPrompt`, `codemirror/slash-menu.ts`), note-name autocomplete after `/` at the start of a line, a code-language picker, image paste, rich-text paste converted to Markdown (`codemirror/html-paste.ts`, with a "Paste as plain text" toast), CSV-paste-to-table conversion, callout and `<details>` folding (`codemirror/details-fold.ts`: raw HTML `<details><summary>` sections fold like callouts, start collapsed unless the tag has `open`, and the chevron writes `open` into the note), frontmatter shown as typed on a tinted panel (`codemirror/frontmatter-block.ts`; it folds like a heading section, from a chevron just outside the panel, into one line: its `title`, then every tag as a pill (`frontmatterSummary`); a spacer block keeps text that follows the closing `---` directly clear of it), heading section folding (`codemirror/heading-fold.ts`: a top-level `#`–`######` heading folds everything up to the next heading of the same or a higher level, blank lines before it kept; a chevron hangs in the leading margin where the `#`s do, shown on hover and while folded, and steps aside on the caret's lines where the `#`s show; a folded heading ends in a `…` that unfolds it; Ctrl/Cmd+Shift+. folds or unfolds the caret's section and Ctrl/Cmd+Shift+, unfolds every heading, also in the palette, leaving callouts and `<details>` as they are; `useCodeMirrorHeadingFold` keeps a note's folded headings for the visit in `atom_headingFolds`, by path and heading line), no tint on the caret's line, optional line numbers aligned with their text (`codemirror/line-numbers.ts`: gutter cells beside headings and fenced code, a callout's first line and the headings and code inside a callout included, take the line's padding and line height, mirrored in `editor-typography.scss`), optional Git Changes inline diff (`codemirror/git-changes.ts`, `atom_showGitChanges`; on only for a vault file in a disk vault whose access is allowed (not while `atom_isVaultPending`), fed by `useGitBaseline`, which `MarkdownEditor` calls after `useCodeMirrorEditor`; `useCodeMirrorEditor` takes a `gitChanges` prop that switches its compartment), optional invisibles (`codemirror/invisibles.ts`, `atom_showInvisibles`: ¶ on empty lines, dots for spaces, arrows for tabs), optional paragraph dimming (`codemirror/flow-mode.ts`, on when Focus is "Dim other paragraphs" or "Dim other sentences": dims all but the caret's paragraph, or sentence, and keeps the caret line centered), and live markers (`codemirror/live-markers.ts`: inline marks show dimmed while the caret or selection touches their token, a heading's `#`s and a quote's `>`s on the caret's lines, hidden elsewhere (`codemirror/syntax-reveal.ts`; an unfocused editor hides them all); a heading's `#`s and a quote's or callout's `>` hang faintly in the margin, out of the text flow (a row holding only its marks, like `## ` before the first letter, keeps its height); list markers stay inline as typed and nested items keep their own spaces (drawn letter-wide in the monospace face), so a list looks just like its Markdown; a task's marker takes its status colour). The editor's `SearchPill` floats over the sheet's top margin (`PaneLeaf`), and CodeMirror keeps the caret below it when scrolling (`--pane-top-room` as its top scroll margin, `codemirror/extensions.ts`; unset on mobile). The note's page (`.editor-sheet`) is one with the content sheet behind it: inside the editor's page (`.app-sheet`) it has no fill, border or shadow of its own (`editor.scss`), so the text sits straight on the page; on the tool pages, outside that sheet, the same class is still a rounded paper card; its side edges line up with the first tab (1rem, 1.25rem from 640px). The panel carries a fine paper grain (`--paper-grain`, a tiled SVG noise defined per theme in `globals.scss`) that moves with its element (not fixed to the viewport, which shimmered and repainted every frame while the sidebar slid). The text is set as a reading page (`editor-typography.scss`): wide page margins that grow with the pane (20px on phones up to 56px on wide panes, `useEditorAppearance`; the leading one is never narrower than the hanging `#`/`>` marks need, `MARGIN_MARKS_ROOM` × the text size, about 38px at 17px, so they stay on the sheet in narrow panes), a centered column that grows with the sheet up to a fixed width that the text size doesn't change (`--editor-measure: clamp(32rem, 85%, 38rem)`, at most 608px, about 64 characters at 17px; with Full Width on (`atom_fullWidth`, the default, Settings → Appearance) the sheet gets `data-full-width` and the column fills it, inside the page margins, the `.editor-measure` wrapper), a page's margins above and below (2rem, 3rem from 640px, above the first line, never less than the pane title's `--pane-top-room` so the first line clears the title; 40% of the window's height below the last, so it can be written mid-window), body text as ink a step softer than the headings (92% of `--fg`), plain greedy wrapping (no `text-wrap: pretty` or `balance`, which re-break earlier lines as you type and make words hop under the caret), body text tracked −0.011em (0 in a monospace face), code (inline and fenced) in Geist Mono at the body size and line height, with contextual alternates and a slashed zero — only headings change size; frontmatter, pills, chips, link marks, calc results, embeds and diagram source are set at the body size too, and a Major Third heading scale (1.953em / 1.563em / 1.25em / 1.125em / 1em / 0.875em, from the `cm-heading-N` line classes in `codemirror/highlight.ts`; line height 1.2 / 1.3 / 1.4, semibold) with tighter tracking and no padding above or below, so only real blank lines space a heading from its neighbours.

A text file that isn't a note (`utils/file-kinds.ts`: code, JSON, YAML, CSV, plain text…) opens in the same editor as plain text (`codemirror/plain-text-extensions.ts`, chosen from `filePath` when the view is created; the editor is remounted per file): highlighted by its language (matched from the file name in `@codemirror/language-data`, loaded before the view), in the code font, with none of a note's Markdown rendering, slash menu, shortcodes, wikilinks, tables or Markdown paste, and Tab indents. Such files are never indexed.

## Local State & Storage
- State: `atom_activeEditorView`, `atom_isEditorFocused`, `atom_fileMetadata` (to resolve cross-note formula refs), `atom_wordWrap`, `atom_lineNumbers`, `atom_showWordCount`, `atom_vimMode`, `atom_focusMode` (`"dim"` turns on flow mode at the paragraph level, `"sentence"` at the sentence level), `atom_headingFolds` (in memory, this visit), `atom_vaultHandle`, `atom_currentDirectoryHandle`, `atom_pendingScrollTarget`, `atom_isAiConfigured`, `atom_aiBuilderRequest`. Pill and dialog state is local useState.
- Persistence: Editor preferences live in `localStorage` (`wordWrap`, `lineNumbers`, `vimMode`, `focusMode`). Pasted images are written into the local vault through the File System Access API (`savePastedImage`).
- An empty note (not a template) shows [EmptyNoteTemplates](EmptyNoteTemplates.md): template pills that fill the note in one click (or, in a vault with no templates, **Browse template packs**), gone as soon as there is text. Every template insert (pills, `/template`) plays a short slide-in on the text (`insertExpandedTemplate` adds `cm-template-in` to the content for 260ms).
- Any other note can be saved as a template (`/save-template` slash entry, `onSaveAsTemplate`, and the palette's **Save as template…** through `hermes:save-as-template`; `useFileSystem().saveAsTemplate`, `use-template-save.ts`), named after its first heading. The palette's **Insert template…** (`hermes:insert-vault-template`) opens the template picker for the active pane; selected text fills `{{selection}}` and is replaced. Blanks a template leaves (`{{task_1}}`) show as grey pills in every note (not in code) and Tab / Shift+Tab select them (`codemirror/template-blanks.ts`; Esc turns that off for the note; "Template ready ✦" once none are left; a click on a blank pill selects it).
- A note in `templates/` (directly, or one folder down in a pack) is a template note (`use-template-note.ts`, which also owns save-as-template and the palette events: `isTemplatePath` with `atom_templatesFolder`). It shows [TemplateStrip](TemplateStrip.md) above the text; its fields render as plain-language pills ("Today's date", "Ask: Owner"; `codemirror/template-field-pills.ts`, switched on with the `setTemplateNote` effect; the source shows while the caret touches a field; unknown tokens stay as typed); and `onInsertTemplateField` / `onAskTemplateQuestion` go to the slash callbacks, which turns on the **Template field** slash entry (`/field`) and the `{{` field menu (`codemirror/template-field-completion.ts`, plain names from `app/utils/templates/template-fields.ts`, matched by token name or a word of the name). Picking a field inserts the whole token, replacing a `}}` already after the caret; **Ask a question…** / **Blank to fill in…** ask for the name in a dialog and insert `{{prompt:Question}}` / `{{Name}}`. `{{date}}` / `{{time}}` typed by hand are not taken for the `{date}` / `{time}` shortcodes in any note.
- Features come from composable hooks in `../hooks`: `use-editor-appearance`, `use-codemirror-{editor,features,templates,table,image,code-language-picker,callout-fold,callout-type,heading-fold}`, `use-vault-template-insert` (the slash menu's **Template** entry, `/template` or `/tpl`, offered while a vault is open: pick a vault template, answer its prompts, then insert it at the caret as one undo step with the caret at `{{cursor}}`; an empty note gets the whole template including non-routing frontmatter, otherwise only the body; nothing is inserted if the editor went away meanwhile), and `use-cross-file-tables` (reads notes referenced by `=[[Note]]!B5` formulas and pushes them into the editor via `setFormulaFileTables` from `codemirror/table-formulas.ts`).

## Dependencies
- Core: `@codemirror/view`, `DatePickerCallout`, `WikiLinkDialog`, `TaskDialog`, the render pieces in [`markdown-editor/`](markdown-editor/README.md) (`EditorPills`, `LinkInsertDialog`, `FoldChevrons`, `VimStatusPill` with `useVimStatus`, `WordCountPill` in the active pane when `atom_showWordCount` is on, `EditorOutline` when `atom_showOutline` is on, and `VimStatusPill` steps left of it), `useEditorPasteHandlers` ("Convert to table?" confirm on CSV paste, image saving), `useScrollToPendingTarget`, `useFileSystem`.
- Zero-Cloud: No network or telemetry side effects. Opening a link pill calls `window.open` after a user click. AI actions only set `atom_aiBuilderRequest`; the request itself is made by the AI dialogs.

## Quick Usage
```tsx
import MarkdownEditor from "./MarkdownEditor";

<MarkdownEditor value={content} onChange={setContent} filePath={path} isActivePane />
```

## Props Overview
| Prop | Type | Default | Description |
|---|---|---|---|
| value | `string` |  | Document text. A change from outside the editor (a reload, a line AI Chat added to this note) is applied as the one changed range (`changedRange` in `utils/text-diff.ts`), so the selection, scroll and undo history map through it |
| onChange | `(value: string) => void` |  | Change handler |
| filePath? | `string` | `"draft"` | Vault path (for image paste, scroll targets and formula refs) |
| placeholder? | `string` | `"Type / for templates"` | Empty-state text |
| onWikiLinkClick? | `(name: string) => void` |  | `[[link]]` navigation (`PaneLeaf` passes `openOrCreateLink`, which also creates missing notes) |
| onFileLinkClick? | `(href: string) => void` |  | Markdown links to a vault path, `[Editor](./app/editor/README.md)` (`PaneLeaf` passes `openFileLink` with the note's path; a missing file is reported, never created). Ctrl/Cmd+click, the link pill and table cells' rendered links all reach it |
| isActivePane? | `boolean` |  | Pane context |

## The active-view hook
- Active-view registration (claim on create/activation, release on unmount) lives in `hooks/use-active-editor-view.ts`, `useActiveEditorView(viewRef, { isActivePane, enabled })`.
