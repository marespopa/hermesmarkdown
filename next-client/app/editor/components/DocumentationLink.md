# DocumentationLink

Description: A book icon linking to `/documentation`, with a tooltip and accessible Documentation label. It sits in `ShellPage` headers immediately before the command search control; `compact` is a 28px circular variant. F1 opens the same page from anywhere in the editor (`EditorShell`).

## Dependencies
- Core: `TextLink`, `Tooltip`, `react-icons/hi`.
- Zero-Cloud: No network or telemetry side effects.
