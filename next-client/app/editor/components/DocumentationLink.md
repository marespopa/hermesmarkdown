# DocumentationLink

Description: A book icon linking to `/documentation`, with a tooltip and accessible Documentation label. Its default 32px button is shared by the editor and `ShellPage` headers immediately before their command search controls; `compact` uses the sidebar toolbar's 28px circular control.

## Dependencies
- Core: `TextLink`, `Tooltip`, `react-icons/hi`.
- Zero-Cloud: No network or telemetry side effects.
