# DocumentationLink

Description: A book icon linking to `/documentation`, with a tooltip and accessible Documentation label. It sits in `ShellPage` headers before the Settings button and the command search control, in the corner buttons' look ([CornerButton](CornerButton.md): the search pill's height, tint and rounding); `compact` is a 28px circular variant with no tint. F1 opens the same page from anywhere in the editor (`EditorShell`).

## Dependencies
- Core: `TextLink`, `Tooltip`, `react-icons/hi`.
- Zero-Cloud: No network or telemetry side effects.
