# home-feed

Building blocks of [`HomeFeed`](../HomeFeed.md).

| File               | Role                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| :----------------- | :----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `feed-model.ts`    | Pure model: `isFeedPath()` (Markdown only; no dotfolders such as `.hermes/`/`.obsidian/`, no `_`-prefixed meta), `feedTitle()` (frontmatter title, else file name; delegates to `noteDisplayTitle` in `app/utils/note-display.ts`), `dayLabel()` ("Today", "Yesterday", weekday, short date), `buildFeed(metadata, displayItems, now)` (newest first; notes missing from the privacy display items are left out before day labels are assigned; each entry carries `isSensitive` and `previewStyle`), `buildWeek(feed, now)` (the seven days ending today, oldest first, each with its note count and first feed row; counts from the built feed, so hidden notes never count) |
| `greetings.ts`     | `timeOfDay()` (morning from 5, afternoon from 12, evening from 17, night from 22), `greeting()` ("Good morning/afternoon/evening, Ada!", "Up late, Ada!" at night; no name when unset)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| `FeedVault.tsx`    | The bar at the top of the feed with a vault open: vault icon, name (`vaultDisplayName()`: a browser or GitHub vault's display name, else the folder name), where it lives, and **Close vault** (confirm, then `closeVault`)                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| `FeedHeader.tsx`   | Greeting ("Good morning, Ada!"), weekday with an accent dot; month and day on the right; `children` (the week strip) below                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| `WeekStrip.tsx`    | The last seven days under the header: weekday initial, date (today in the accent color, `aria-current="date"`), and a dot on days with notes. A day with notes calls `onJump(firstIndex)`; empty days are disabled. `activeDay` (the selected row's day) gets the raised background. Accessible name: "Saturday, October 3, 2 notes"                                                                                                                                                                                                                                                                                                                                           |
| `FeedRow.tsx`      | One note: gutter day label, title (with a `SensitiveBadge` lock for sensitive notes), 3-line preview. `previewStyle` `masked` shows `MASKED_PREVIEW` (sr-only "Preview hidden"); `blurred` blurs the real preview until the row is hovered or keyboard-focused (not on selection; sr-only "Preview blurred")                                                                                                                                                                                                                                                                                                                                                                   |
| `FeedStart.tsx`    | The body with no vault open: "Open a vault to see your notes here." with `VaultActionButtons` (left out where no vault kind is supported), then "Or just write" with **New Note** and **Open File…**                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| `FeedSkeleton.tsx` | Pulsing placeholder rows (FeedRow layout; `rows`, default 3) shown while the vault loads and no notes are listed yet; `EditorSkeleton` shows five                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| `FeedStatus.tsx`   | Indexing status line; rotates through `INDEXING_VERBS` every `ROTATE_MS` (stable `aria-label` for screen readers)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| `FeedBar.tsx`      | Floating bottom bar: the search pill (`data-palette-anchor`, same classes as the palette's `PaletteSearchBar`, morphs into it; its `>` opens command mode), and `+` new note (below 400px the placeholder shortens); lifted above the on-screen keyboard. `placeholder` replaces the pill's wording (the no-vault feed's "Search commands…")                                                                                                                                                                                                                                                                                                                                   |
