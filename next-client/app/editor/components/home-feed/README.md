# home-feed

Building blocks of [`HomeFeed`](../HomeFeed.md).

| File               | Role                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| :----------------- | :----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `feed-model.ts`    | Pure model: `isFeedPath()` (Markdown only; no dotfolders such as `.hermes/`/`.obsidian/`, no `_`-prefixed meta), `feedTitle()` (frontmatter title, else file name; delegates to `noteDisplayTitle` in `app/utils/note-display.ts`), `dayLabel()` ("Today", "Yesterday", full weekday, short date), `buildFeed(metadata, displayItems, now, templatesFolder?, pinnedPaths?)` (pinned notes first, in pin order, the first labelled "Pinned"; then the rest newest first; notes missing from the privacy display items are left out before labels are assigned; each entry carries `isPinned`, `isSensitive`, `previewStyle` and `fileName` — the file name with its extension, null for sensitive notes — and `tags`, empty for sensitive notes; an optional `tagFilter` keeps only notes carrying every listed tag, before labels are assigned), `feedTags(feed)` (every tag with its note count, most used first, then most recently used, then by name), `openFeedTasks(feed, metadata, now)` (unchecked tasks of non-sensitive feed notes changed in the last `OPEN_TASK_DAYS` (7) days, today included; newest note first, then by line), `feedStats(feed, now)` (note count, notes changed since midnight), `withTodaySheet(feed, { path, exists }, now)` (today's sheet first after the pins, so it heads "Today", marked `todaySheet: "existing"`; with no sheet yet a `todaySheet: "missing"` row titled "Start today's sheet" in its place; a pinned sheet stays pinned, and a sheet the feed hides adds nothing; labels recomputed) |
| `greetings.ts`     | `timeOfDay()` (morning from 5, afternoon from 12, evening from 17, night from 22), `greeting()` ("Good morning/afternoon/evening, Ada!", "Up late, Ada!" at night; no name when unset)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| `FeedVault.tsx`    | The bar at the top of the feed with a vault open: vault icon, name (`vaultDisplayName()` from `vault-atoms.ts`, re-exported: a browser or GitHub vault's display name, else the folder name), where it lives, The name opens the one vault menu: the `MENU_RECENT_LIMIT` (5) newest recent vaults from `useRecentVaults`, then **Open vault…**, **Create vault…**, **Browser vaults…** (as supported), **Rename vault…** for a browser vault (prompt, then `renameBrowserVault`), then **Refresh vault** and **Close vault** (confirm, then `closeVault`). Below `sm` only the name shows. Exports `VAULT_KIND_LABEL` and `VaultKindIcon`                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| `FeedHeader.tsx`   | Greeting ("Good morning, Ada!"), weekday with an accent dot; month and day on the right; `children` below (the stats line)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| `FeedStats.tsx`    | The faint line under the weekday (rendered as `FeedHeader`'s children): "128 notes · 3 edited today · 5 open tasks"; zero parts left out, nothing for an empty feed. With `tasksToggle`, "5 open tasks" is a button with a chevron that folds `FeedTasks` (`aria-expanded`, `aria-controls`; state in `atom_homeTasksCollapsed`, localStorage) |
| `FeedTasks.tsx`    | "Open tasks" list right under the stats line, also inside `FeedHeader`, with no header or gutter of its own so it lines up with the greeting and tags; hidden when folded (from the stats line) or empty. Up to `FEED_TASK_LIMIT` (8) tasks, then "+N more" / "Fewer"; each is a small open circle, the task text in muted type and its note's title in faint caption type after it; hover or focus brightens the text and turns the circle sage. Calls `onOpenTask(path, line)` (0-indexed) |
| `FeedTags.tsx`     | One row of tag chips under the header: the `FEED_TAG_LIMIT` (8) most used tags (`feedTags`), "+N" to show the rest ("Fewer" to fold them), and "× Clear" while a filter is on. Chips toggle (`aria-pressed`); a note must carry every selected tag. Selected tags always show, even past the limit or once no note carries them. Hidden when the feed has no tags. Accessible name: "#work, 12 notes" |
| `FeedRow.tsx`      | One note: the day label (or "Pinned") in the left gutter, title (with a `SensitiveBadge` lock for sensitive notes), up to 3 lines of preview, the file name in small faint type (not for sensitive notes); rounded fill when selected or hovered. A pin button (top right, `onTogglePin`) shows on hover, focus or selection, never on touch-only screens (`any-hover: none`, so a mouse on a tablet still gets it); a long press (`useLongPress`), right-click or the context-menu key opens the row's menu (Open, Pin / Unpin). No text selection or iOS callout on the row. Today's sheet (`todaySheet`) shows the header's accent dot after its title (accessible name "<title>, today's sheet"); the "missing" row has a muted title, no pin, and a one-item menu (**Start**). `previewStyle` `masked` shows `MASKED_PREVIEW` (sr-only "Preview hidden"); `blurred` blurs the real preview until the row is hovered or keyboard-focused (not on selection; sr-only "Preview blurred")                                                                                                                                                                                                                                                                                                                                                                   |
| `use-long-press.ts` | `useLongPress(onLongPress)`: touch handlers that call back with the touch point after `LONG_PRESS_MS` (500) unless the finger lifts, moves more than 10px or a second finger lands; `shouldSkipClick()` swallows the click a hold may send, once; `didFire()` lets the row ignore Android's duplicate contextmenu event |
| `RecentVaultList.tsx` | "Recent vaults" on the no-vault start: one row per recently opened vault (kind icon, name, where it lives); click reopens it, the hover × (always shown on touch screens) drops it from the list without touching its files. Renders nothing with no recents |
| `FeedStart.tsx`    | The body with no vault open: `RecentVaultList`, then "Open a vault to see your notes here." with `VaultActionButtons` (left out where no vault kind is supported), then "Or just write" with **New Note** and **Open File…**                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| `FeedSkeleton.tsx` | Pulsing placeholder rows (FeedRow layout and line heights: gutter label, title, two preview lines, file name; `rows`, default 3) shown while the vault loads and no notes are listed yet; `EditorSkeleton` shows five. Also exports `FeedVaultSkeleton` (the vault bar, for `EditorSkeleton`)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| `FeedStatus.tsx`   | Indexing status line; rotates through `INDEXING_VERBS` every `ROTATE_MS` (stable `aria-label` for screen readers)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| `FeedBar.tsx`      | Floating bottom bar: the search pill (`data-palette-anchor`, same classes as the palette's `PaletteSearchBar`, morphs into it; its `>` opens command mode), and `+` new note (below 400px the placeholder shortens); lifted above the on-screen keyboard. `placeholder` replaces the pill's wording (the no-vault feed's "Search commands…").                                                                                                                                                                                                                                                                                                                                   |
