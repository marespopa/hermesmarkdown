# home-feed

Building blocks of [`HomeFeed`](../HomeFeed.md).

| File               | Role                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| :----------------- | :----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `feed-model.ts`    | Pure model: `isFeedPath()` (Markdown only; no dotfolders such as `.hermes/`/`.obsidian/`, no `_`-prefixed meta), `feedTitle()` (frontmatter title, else file name; delegates to `noteDisplayTitle` in `app/utils/note-display.ts`), `dayLabel()` ("Today", "Yesterday", full weekday, short date), `buildFeed(metadata, displayItems, now, templatesFolder?, pinnedPaths?)` (pinned notes first, in pin order, the first labelled "Pinned"; then the rest newest first; notes missing from the privacy display items are left out before labels are assigned; each entry carries `isPinned`, `isSensitive`, `previewStyle` and `fileName` — the file name with its extension, null for sensitive notes), `buildWeek(feed, now)` (the seven days ending today, oldest first, each with its note count and first feed row, preferring an unpinned one; counts from the built feed, so hidden notes never count) |
| `greetings.ts`     | `timeOfDay()` (morning from 5, afternoon from 12, evening from 17, night from 22), `greeting()` ("Good morning/afternoon/evening, Ada!", "Up late, Ada!" at night; no name when unset)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| `FeedVault.tsx`    | The bar at the top of the feed with a vault open: vault icon, name (`vaultDisplayName()`: a browser or GitHub vault's display name, else the folder name), where it lives, The name opens the one vault menu: the `MENU_RECENT_LIMIT` (5) newest recent vaults from `useRecentVaults`, then **Open vault…**, **Create vault…**, **Browser vaults…** (as supported), then **Refresh vault** and **Close vault** (confirm, then `closeVault`). Below `sm` only the name shows. Exports `VAULT_KIND_LABEL` and `VaultKindIcon`                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| `FeedHeader.tsx`   | Greeting ("Good morning, Ada!"), weekday with an accent dot; month and day on the right; `children` (the week strip) below                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| `WeekStrip.tsx`    | The last seven days under the header: weekday initial, date (today in the accent color, `aria-current="date"`), and a dot on days with notes. A day with notes calls `onJump(firstIndex)`; empty days are disabled. `activeDay` (the selected row's day) gets the raised background. Accessible name: "Saturday, October 3, 2 notes"                                                                                                                                                                                                                                                                                                                                           |
| `FeedRow.tsx`      | One note: the day label (or "Pinned") in the left gutter, title (with a `SensitiveBadge` lock for sensitive notes), up to 3 lines of preview, the file name in small faint type (not for sensitive notes); rounded fill when selected or hovered. A pin button (top right, `onTogglePin`) shows on hover, focus or selection, never on touch screens; a long press (`useLongPress`), right-click or the context-menu key opens the row's menu (Open, Pin / Unpin). No text selection or iOS callout on the row. `previewStyle` `masked` shows `MASKED_PREVIEW` (sr-only "Preview hidden"); `blurred` blurs the real preview until the row is hovered or keyboard-focused (not on selection; sr-only "Preview blurred")                                                                                                                                                                                                                                                                                                                                                                   |
| `use-long-press.ts` | `useLongPress(onLongPress)`: touch handlers that call back with the touch point after `LONG_PRESS_MS` (500) unless the finger lifts, moves more than 10px or a second finger lands; `shouldSkipClick()` swallows the click a hold may send, once; `didFire()` lets the row ignore Android's duplicate contextmenu event |
| `RecentVaultList.tsx` | "Recent vaults" on the no-vault start: one row per recently opened vault (kind icon, name, where it lives); click reopens it, the hover × (always shown on touch screens) drops it from the list without touching its files. Renders nothing with no recents |
| `FeedStart.tsx`    | The body with no vault open: `RecentVaultList`, then "Open a vault to see your notes here." with `VaultActionButtons` (left out where no vault kind is supported), then "Or just write" with **New Note** and **Open File…**                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| `FeedSkeleton.tsx` | Pulsing placeholder rows (FeedRow layout, gutter label included; `rows`, default 3) shown while the vault loads and no notes are listed yet; `EditorSkeleton` shows five                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| `FeedStatus.tsx`   | Indexing status line; rotates through `INDEXING_VERBS` every `ROTATE_MS` (stable `aria-label` for screen readers)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| `FeedBar.tsx`      | Floating bottom bar: the search pill (`data-palette-anchor`, same classes as the palette's `PaletteSearchBar`, morphs into it; its `>` opens command mode), and `+` new note (below 400px the placeholder shortens); lifted above the on-screen keyboard. `placeholder` replaces the pill's wording (the no-vault feed's "Search commands…")                                                                                                                                                                                                                                                                                                                                   |
