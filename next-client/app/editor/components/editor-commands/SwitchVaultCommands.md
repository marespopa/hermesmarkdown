# SwitchVaultCommands

Registers **Switch Vault…** (`switch-vault`, Vault) in the command palette: a menu that lists the top vaults (pinned first, then by `lastOpened` descending, capped to 6) and opens the chosen one via `useRecentVaults().openRecentVault` (which handles permission prompts, browser vs local vaults and failure toasts). Duplicate vault names append type context (e.g. `My Vault (Local)`). When more than 6 recent vaults exist, a **View All Recent Vaults…** (`switch-vault:view-all`) fallback opens the full searchable dialog (`atom_recentVaultsDialogOpen`). It renders nothing unless two or more recent vaults exist; the open vault is listed, disabled with "Current vault". Mounted by `EditorShell`, so it is offered on every `/editor` route.
