# Render raw HTML <details><summary> blocks in notes as foldable sections 

## Desired behavior
Render raw HTML <details><summary> blocks in notes as foldable sections in the editor (and in PDF/HTML export), so notes written in other tools that use the HTML form fold neatly. The summary line stays visible; the body folds. Hermes's own > [!note]- callout-fold already covers notes written in Hermes, so keep this light and consistent with how callout folds look and behave.
